# CodexStation Ω Public — bootstrap draft

> **Status:** public-repository bootstrap specification, not yet the standalone repository.

**Target standalone repository:** `Ivan-Pasev/CodexStation.Omega.Public`

CodexStation Ω Public is intended to be the **public constitutional anchor, dense knowledge-carrier surface, reproducible reference implementation, and cross-provider distribution source** for the CodexStation Ω architecture.

It is not the private R&D canon and must never silently replace it.

## Core publication law

```text
PRIVATE_R&D_CANON
  -> PUBLICATION_FILTER
  -> PUBLIC_OMEGA_CANON
  -> {CHATGPT_PLUGIN_DIST, GEMINI_NOTEBOOK_DIST, PUBLIC_RESEARCH_DIST}
```

Hard boundaries:

```text
PUBLIC_REPO != PRIVATE_CANON
PUBLICATION != AUTHORITY_PROMOTION
MODEL != REALITY
CLAIM != EVIDENCE
FORMAL_PROOF != EMPIRICAL_CONFIRMATION
IMPLEMENTATION_PASS != SCIENTIFIC_PASS
SAME_LABEL != SAME_LINEAGE
PLATFORM_PROFILE != CANON_FORK
```

## Design objective

The repository should expose the strongest **publicly defensible** CodexStation primitives for:

- constitutional cybernetic orchestration;
- provenance-preserving knowledge metabolism;
- typed claim/evidence/status control;
- capability/authority routing;
- bounded recursive research and engineering;
- public verification surfaces;
- reproducible software and machine contracts;
- provider-independent distribution into ChatGPT/Codex and Gemini Notebook.

“Digital 2.0” and “Civilization 2.0” are project-level design horizons, not empirical claims of achieved societal transformation.

## Dense-carrier strategy

The public repo should intentionally use a **small number of large semantic carriers**, plus a very small control surface.

Target top-level corpus:

```text
README.md
AGENTS.md
OMEGA_CORE.md
OMEGA_CRYSTAL.md
OMEGA_SKILL_SPINDLE.md
OMEGA_THEOREMATIC_SPINE.md
OMEGA_PUBLIC_ANCHORS.md
MANIFEST.json
```

The platform distributions are compiled from these files. They are not separately authored canons.

### OMEGA_CORE.md

Provider-independent operating core:
MLCO lineage, Ω NEXT constitutional root, KBI role, HighestOne selection law, Omnius mission compilation, source precedence, authority boundaries, state/continuity semantics.

### OMEGA_CRYSTAL.md

Large public semantic crystal:
constitutional ontology, formal/theorematic registry, research/verification semantics, engineering/agentic systems semantics, domain atlas, continuity/evidence semantics, non-collapse laws, negative results and failure modes.

The source-of-truth public Crystal may be larger than a single Gemini Notebook source. Distribution compilers may shard it **without changing semantics**.

### OMEGA_SKILL_SPINDLE.md

Portable skill/capability method registry:
intent, preconditions, method, emitted artifacts, guards, evidence requirements, host bindings, authority ceilings, freshness, tests and failure modes.

### OMEGA_THEOREMATIC_SPINE.md

Definitions, theorem targets, proven/finite-tested/open status, assumptions, dependencies, countermodels, proof artifacts and empirical relevance. It must never erase the difference among theorem target, finite machine evidence, formal proof and measurement.

### OMEGA_PUBLIC_ANCHORS.md

Public repositories, papers, datasets, standards, public experiments and verifiable external anchors. It is the bridge from internal terminology to inspectable public evidence.

## Distribution law

### Gemini Notebook

The Notebook distribution should prefer a few dense source carriers. A build step must count words before release and shard any source that exceeds the current Gemini Notebook per-source limit. Cross-notebook state is carried through visible artifacts, not hidden chat memory.

### ChatGPT plugin

The plugin remains a **thin orchestration kernel with dense reference carriers**. Skill files stay compact. Large carriers live under a reference namespace and are selected only when needed.

`SKILL != HOST_CAPABILITY`

Presence of a reference or skill file never implies tool availability or execution authority.

## Publication filter

Before any private source is promoted into this public repository, perform:

```text
SOURCE
-> LINEAGE
-> SECRET/PII CHECK
-> LICENSE/IP CHECK
-> CLAIM/EVIDENCE CLASSIFICATION
-> AUTHORITY CEILING
-> PUBLIC-INTEREST TEST
-> REDACTION/COMPRESSION
-> PUBLICATION WITNESS
-> COMMIT
```

A private source may inform a public carrier without being copied verbatim.

## Repository role in the Ω architecture

The standalone public repo should become:

1. the stable public URI namespace for constitutional objects;
2. the source of public machine-readable manifests and schemas;
3. the source for public ChatGPT and Gemini distribution builds;
4. a reproducible evidence/witness surface;
5. a discovery surface for researchers and developers;
6. a forkable reference implementation;
7. an anchor for public papers and release artifacts.

It should **not** become:

- the only copy of canonical state;
- the private research notebook;
- an unfiltered dump of historical packs;
- a place where source-reported PASS becomes truth;
- a place where model-generated terminology silently acquires authority.

## Genesis rule

Until the standalone repository exists, this directory is only a bootstrap surface inside `GILC.CodexStation`.

No file here supersedes Ω NEXT or any source lineage merely by being public.
