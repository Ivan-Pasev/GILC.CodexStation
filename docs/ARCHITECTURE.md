# Ω101 Architecture

Ω101 introduces a bounded persistent cognitive lineage above the Ω100 carrier/runtime layer.

## Invariants

1. Identity continuity.
2. Memory provenance.
3. Self/world separation.
4. Initiative is not authority.
5. Constitutional mutation is gated.
6. Consequential cognition is reconstructible from evidence and state transitions.
7. Phenomenal consciousness remains UNKNOWN.

## Dual-root continuity

`station_root != entity_root`

A migration may change the station root only while entity identity/lineage remains independently verified.

## Authority lattice

A0 reasoning; A1 read/query; A2 reversible mutation; A3 persistent mutation; A4 external side effect; A5 constitutional mutation.
